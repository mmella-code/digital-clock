
# Digital Clock

## About the Project
This is a simple digital clock built using HTML, CSS, and JavaScript. It displays the current time and updates automatically every second.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Displays the current time.
- Updates automatically every second.
- Simple and user-friendly interface.
- Responsive design.

## What I Learned
- Working with JavaScript Date objects.
- Using setInterval() to update time.
- Manipulating the DOM.
- Styling a webpage using CSS.
